# UNFPA-Style Programme Coordinator Roles — Scoring Pattern

## Pattern Recognition

UNFPA International Programme Coordinator (P-3/P-4) roles follow a consistent template across duty stations (Timor-Leste, Yemen, Mozambique, etc.). When evaluating any UNFPA programme coordinator role:

### Hard Filters First
- **Ukraine** — Any Ukraine duty station = FAIL (Aden Yemen is OK per user rules, but check carefully)
- **Nationals-only** — Check if position is NOA/NOB/NOC = FAIL for international candidates
- **Grade floor** — P-3 minimum for User's profile

### Scoring Template (Typical Range: 58-68)

| Parameter | Typical Score | Notes |
|---|---|---|
| P1 Domain/Technical | 10-15/25 | SRHR/gender/GBV programming is far from User's ICT/telecom core. Only overlap is generic programme management. |
| P2 Seniority | 10-12/15 | P-3 requires ~5 years; User has 30+. Overqualified but not in a relevant way. |
| P3 UN/IFI Fit | 8-12/15 | User has UN experience but it's ICT-focused, not health/gender. |
| P4 Education | 4-6/10 | Engineering degree vs. public health/development required. |
| P5 Language | 8-10/10 | English fluency + Russian (UN language) = strong fit. |
| P6 Logistics | 8-10/10 | Timor-Leste/Yemen/Mozambique = international duty stations, no visa issues. |
| P7 Competitive | 5-8/15 | Specialized health/gender role attracts domain experts; User is an outsider. |

**Typical verdict: 🟡 STRETCH (55-68%)**

### Application Strategy (If Pursuing)
- Frame UNICEF device/connectivity work as enabling health outcomes (connecting health facilities, digital health platforms)
- Emphasize capacity building and training from COO experience
- Position multi-country developing-world exposure as directly transferable
- Strong cover letter required to bridge ICT-to-health narrative
